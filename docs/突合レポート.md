# 突合レポート — 益田先生の古文プリント 2 点

テンプレートを作るにあたって、次の 2 つのプリントを突き合わせた。

| | 『古今著聞集』「能は歌詠み」 | 『徒然草』「あだし野の露消ゆる時なく」 |
|---|---|---|
| 構成 | 文法プリント（表・裏）と読解プリント①〜③など 6 枚 | 授業プリント①（表）・②（裏）の 2 枚 |
| 図形 | 64 個（枠・巻物・挿絵・テキストボックス） | 10 個 |
| 分析の出どころ | 前回の作業で原本を計測した記録（原本ファイルは環境のリセットで消えたため、今回は記録を使った） | `docs/原本_徒然草_あだし野の露.docx` を今回計測 |

## 1. 共通していた設計 → テンプレートの標準

二つのプリントは同じ設計で作られていた。テンプレートはこれをそのまま受け継ぐ（組版は原本の XML をそのまま使うので、数値も原本どおり）。

| 項目 | 値 | 両者 |
|---|---|---|
| 用紙 | A4 横（297×210mm） | 一致 |
| 文字の向き | 縦書き（右から左へ） | 一致 |
| 余白 | 上下左右 12.7mm（720 twip） | 一致 |
| 行送り | 18pt（docGrid 360） | 一致 |
| 段組 | ヘッダ・氏名・題名は 1 段、本文・訳は 2 段（セクションの連続区切りで切り替え） | 一致 |
| 氏名欄 | 「二年　　組　　　　番　氏名」を 2800 字分字下げ | 一致（数値まで同じ） |
| ヘッダ | 【古典探究】『作品』「章段」　プリント名　…　表／裏（HG丸ｺﾞｼｯｸM-PRO） | 一致 |
| 題名 | はれのそら明朝 14pt を枠で囲む | 一致 |
| 本文 | UD デジタル教科書体 N-B 11pt、行送り 1.5 | 一致 |
| 傍線 | 傍線を引く語に下線、その前に上付きの丸数字 | 一致 |
| 現代語訳・文法事項 | HG丸ｺﾞｼｯｸM-PRO 9pt、罫線で囲んだ欄 | 一致 |
| 答え | 赤字（FF0000） | 一致 |
| 設問 | ☆１ ☆２ …（読解プリントは ❶❷ ★ も） | 一致 |
| 飾り | 【ー読解のためにー】の見出し、自／他 の軸 | 一致 |

## 2. 違っていた点 → テンプレートでの扱い

| 違い | 能は歌詠み | あだし野の露 | テンプレートでの扱い |
|---|---|---|---|
| プリントの型 | 文法プリント（本文＋品詞分解）と読解プリント | 授業プリント（表＝本文・訳・文法事項・文学史／裏＝本文・設問・図解） | **授業プリント型**をテンプレート化した。品詞分解は「行を組み立てる機能」として取り込み、どの区画にも書ける |
| 隠し答え | 白字（FFFFFF）を併用（243 字） | 赤字のみ | 記法 `{答え}` `{{隠し答え}}` の両方を用意。`--answers` で一括切り替え |
| 文法事項の見出し | 〖文法事項〗 | 【文法事項】 | どちらの括弧でも見出しと判定する |
| 本文フォントの名前 | UD Digi Kyokasho N-B（英語名） | UD デジタル 教科書体 N-B（日本語名） | 同じ書体の別名。Windows ならどちらでも表示されるが、ほかの環境では置き換わることがある。テンプレートは原本の指定のまま |
| 裏面の本文 | 2 段組 | 1 段組 | 原本のまま |

## 3. 原本で見つかった点

`tools/check.py`（表記チェック）と目視で見つけたもの。

| プリント | 場所 | 内容 | 状態 |
|---|---|---|---|
| あだし野の露（表） | 本文 | 「飽かず」の傍線番号が **⑩** になっている。現代語訳では ⑨（不満足）なので ⑨ の誤りと思われる | **未修正**（表面は変えない指示のため） |
| あだし野の露（表） | 本文 | 「⑳あさましき」の ⑳ が上付きになっておらず、「あさましき」に傍線がない | **未修正**（同上） |
| あだし野の露（表） | 現代語訳 | 解答の括弧に半角 `( )` と全角 `（ ）` が混ざっている（③( 定めがない…, ⑤( だよ ), ⑧( 心静かな ), ⑩（ するであろう ) の 4 行） | **未修正**（同上） |
| あだし野の露（裏） | ☆３ | 前の教材『古今著聞集』の設問（「汝は歌詠みな」…）が残っていた | 改訂版で差し替え済み |
| あだし野の露（裏） | 板書例 | 「四十一に足らぬ」「世を貪る心の深く」 | 改訂版で「四十に足らぬ」「心のみ深く」に修正済み |
| あだし野の露（改訂版） | ☆３ | 前回の改訂で、☆３に付いていた枠（角丸四角形）を誤って消していた | 今回修正（図形は原本と同じ 10 個） |
| 能は歌詠み | 品詞分解 ⑦ | 「⑦」ではなく装飾用の別字「➆」が使われていた | 記録のみ（原本が手元にない） |
| 能は歌詠み | 全体 | Word の編集の履歴で、見た目の同じ書式が 70 種類近くに分かれていた | テンプレートでは原本のまま保持（書式表に記録） |

表記チェックは、新しい教材でも同じものを拾えるようにしてある（`python3 tools/check.py data/○○.json`）。

## 4. 今回できなかったこと

- **文法プリント型・読解プリント型のテンプレート**は作っていない。これらは「能は歌詠み」の原本 docx から作るが、原本ファイルが作業環境のリセットで失われているため。原本を添付してもらえれば `tools/make_template.py` で同じように追加できる。
- **Word の実フォントでのページ割り**は確かめられない。HG丸ｺﾞｼｯｸM-PRO などが無い環境では LibreOffice が代替フォントで描くため、原本そのものでも裏面の冒頭が 1 ページ目に食い込む。そこでページ数の代わりに「分量チェック」（原本比の行数見積もり）を入れた。最終確認は Word で行ってほしい。
