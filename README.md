# kobun-print

古典探究の授業プリント（A4横・縦書き）を管理するリポジトリ。

## 収録

| プリント | 原本 | 改訂版 |
|---|---|---|
| 『徒然草』「あだし野の露消ゆる時なく」 | `docs/原本_徒然草_あだし野の露.docx` | `prints/徒然草_あだし野の露_改訂.docx` |

### あだし野の露 — 改訂内容（裏面のみ。表面は原本のまま）

- ☆３を差し替え（前教材『古今著聞集』の設問が残っていたため）→ 三段落の構成と働き
- ☆４を追加 → 本文に「無常」の語が無いのに無常が読み取れるのはなぜか
- 「兼好の主張をまとめよう」の穴埋め図解（第一段落＝主張／第二段落＝根拠①／第三段落＝根拠②／まとめ）
- 解答は赤字（表面の現代語訳・☆１☆２と同じ約束）

改訂版は次で作り直せる。

```bash
python3 tools/edit_adashino.py docs/原本_徒然草_あだし野の露.docx prints/徒然草_あだし野の露_改訂.docx
```
