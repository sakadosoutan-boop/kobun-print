# kobun-print — 古文教材作成用テンプレート

益田先生の古文プリント（A4 横・縦書き）の組版を固定したまま、教材だけを差し替えて
プリントを作るための道具一式。

- **テンプレート**は先生の原本 docx の組版をそのまま使う。作り直していないので、
  枠・巻物・肖像・罫線入りの訳欄などの位置は原本と同じになる
- **教材データ**（JSON）に本文・現代語訳・設問・図解を書くと、テンプレートに流し込んで docx ができる
- 本文や訳の**行数は原本と違ってよい**（区画ごとに増減する）

二つのプリント（『古今著聞集』「能は歌詠み」と『徒然草』「あだし野の露」）を突き合わせた
結果は [docs/突合レポート.md](docs/突合レポート.md) にまとめてある。

## すぐ使う

### Word で書く

`prints/雛形_授業プリント.docx` を開いて、（本文）（現代語訳）…の場所に打ち込む。
各区画は原本と同じ行数の空行を取ってあるので、枠や飾りの位置が崩れない。

### 教材データから組む

```bash
cp data/_雛形_授業プリント.json data/○○.json      # 雛形を写して中身を書く
python3 src/build.py data/○○.json -o build/○○.docx
python3 src/build.py data/○○.json -o build/○○_配布用.docx --answers 空欄
python3 tools/check.py data/○○.json                # 表記チェック
```

書き方の実例は次の 2 つ。

| 教材データ | 中身 |
|---|---|
| `data/徒然草_あだし野の露.json` | 原本（改訂版）そのもの。組むと `prints/徒然草_あだし野の露_改訂.docx` と 1 ドットも違わない |
| `data/例_方丈記_ゆく河の流れ.json` | 別の教材を入れた例。現代語訳 22→15 行、図解 19→16 行など、行数を変えている |

## 授業プリント型の区画

| 表（授業プリント①） | 原本の行数 | 裏（授業プリント②） | 原本の行数 |
|---|---|---|---|
| ヘッダ | 1 | ヘッダ | 1 |
| 題名 | 1 | 題名 | 1 |
| 本文 | 3 | 本文 | 2 |
| 現代語訳 | 22 | 設問（☆１〜☆４：問と答の組） | 答 1・3・3・4 |
| 文法事項 | 5 | 図解 | 19 |
| 見出し・文学史 | 1 | | |
| 文学史 | 3 | | |

氏名欄、【現代語訳】【文法事項】の見出し、【ー読解のためにー】、自／他 の軸は、書かなければ原本の文字のまま。

```json
{
  "meta": { "テンプレート": "template/授業プリント", "題名": "『方丈記』「ゆく河の流れ」" },
  "sheets": {
    "表": {
      "ヘッダ": "【古典探究】 『方丈記』「ゆく河の流れ」　授業プリント①　…　表",
      "題名": "ゆく河の流れ　　",
      "本文": ["ゆく河の流れは[①|絶えずして]、[②|しかも]もとの水に", "…"],
      "現代語訳": ["流れていく河の流れは①（{ 絶えることがなくて }）、しかも", "…"]
    },
    "裏": {
      "設問": [ { "問": "☆１ 「よどみに浮かぶうたかた」は何をたとえたものか。", "答": ["　〔{ 人 }〕と〔{ すみか }〕"] } ],
      "図解": ["〖 長明の無常観をまとめよう 〗", "…"]
    }
  }
}
```

### 書くときの決まり

- **1 要素が 1 段落（縦書きの 1 行目から始まるまとまり）**。長ければ Word が折り返す
- **字下げ**は行頭の全角スペースで書く
- **表の本文の 1 行目**は、題名の枠をよけるため 24 字ほどで切る（原本どおり）
- 行数が原本と同じ区画は原本の段落書式をそのまま使い、違う区画はその区画でいちばん多い書式にそろえる
- 設問はテンプレートの 4 問より少なければ、使わない設問を枠ごと取り除く。多ければ 4 問目の後ろに続ける

### 記法

| 記法 | 意味 | 例 |
|---|---|---|
| `[①\|参り]` | 傍線番号（上付き）＋傍線を引く語 | `初めて[①\|参り][②\|たり]侍` |
| `[#\|語]` | 番号を出現順に自動で振る | `[#\|あり][#\|けり]` |
| `{語}` | 答え（赤字） | `①（{ 立ち消えないで }）` |
| `{{語}}` | 隠し答え（白字。印刷すると空欄に見える） | `( {{動}}　詞)` |
| `_語_` / `^語^` | 傍線のみ／上付きのみ | `はたおりぞ_鳴く_` |
| `<<書式01\|語>>` | 書式表（`template/授業プリント/spans.json`）の書式 | |
| `\[` | 記号そのものを出す | `(\[ ラ行\])` |

### 品詞分解は構造で書ける

どの区画の行にも、次のように書ける（前回の『能は歌詠み』文法プリントの書式）。

```json
{ "品詞分解": { "番号": "①", "品詞": "動詞", "行": "ラ", "活用": "四段", "活用形": "連用",
                "敬語": { "種類": "謙譲語", "から": "作者", "へ": "大臣" } } }
```

→ `① ( 動　詞)([ ラ行] 四段 活用)（連用 形）` と `敬語の種類：〔謙譲 語〕〔作者〕から〔大臣〕への敬意` の 2 行（解答は赤字）。

| 品詞 | 要る項目 |
|---|---|
| 動詞・形容詞・形容動詞 | `行` `活用` `活用形`（補助動詞は `"補助": true`） |
| 助動詞 | `意味` `語` `活用形` |
| 〜助詞 | `語`。任意で `用法` か `意味`、`訳` |

## 組んだときに出る報告

```
→ build/例_方丈記.docx（解答: 原本どおり）
  行数を変えた区画: 表・現代語訳 22→15 行
  分量（表）: 原本 74 行分 → 今回 50 行分（68%）
  分量（裏）: 原本 47 行分 → 今回 37 行分（79%）
```

**分量**は、段組と文字の大きさから縦書き 1 行に入る字数を出し、教材が何行分になるかを
原本と比べたもの。100% 以下なら紙面からはみ出すことはまずない。超えると ⚠ が付く。
（LibreOffice で数えたページ数は当てにならない。実フォントが無いと原本そのものでも裏面の
冒頭が 1 ページ目に食い込むため。最終確認は Word で）

`--answers` で解答の見せ方を切り替えられる。

| 指定 | 何が起きるか |
|---|---|
| `原本どおり` | 赤字は赤字、白字は白字のまま（既定） |
| `答え` | 白字の隠し答えも赤字にして、すべて見せる |
| `空欄` | 赤字の答えも白字にして、すべて空欄にする（配布用） |
| `黒` | すべての答えを黒字にする（モノクロ印刷の解答例） |

ふりがな付きの語の答えも一緒に切り替わる。赤い飾り文字も同じ扱いなので、`空欄` は一度目で確かめてほしい。

## テンプレートを増やす

別の型のプリント（文法プリント・読解プリントなど）を正本にしたいときは、その docx から作る。

```bash
python3 tools/make_template.py 原本.docx --name 文法プリント --data data/○○.json
```

`template/文法プリント/` に組版の正本・書式表・区画表ができ、`data/_雛形_文法プリント.json` に雛形ができる。

## 確かめる

```bash
python3 tests/verify.py
```

1. 原本と改訂版を、スロットに割って組み直しても 1 ドットも変わらないこと
2. テンプレート＋教材データから組んだものが、改訂版と 1 ドットも変わらないこと
3. 行数の違う教材（方丈記）が分量の範囲内で組めること
4. `--answers` の各指定で、消えるべき色の文字が 0 字になること

1・2 の画像照合には LibreOffice と poppler-utils が要る（無ければ文字の照合だけ行う）。
Python 3.10 以上、標準ライブラリのみ。

```bash
sudo apt-get install -y libreoffice-writer poppler-utils fonts-noto-cjk
```
